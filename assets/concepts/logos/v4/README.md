# Weapon Database — Armory Crest v4

Armory Crest is the chosen identity direction. This round tunes the almost-approved design through color balance and small details.

| File | Purpose |
| --- | --- |
| `01-armory-crest-mark.svg` | Editable standalone crest with a transparent surrounding canvas. |
| `01-armory-crest-lockup.svg` | Editable crest beside the two-line Weapon Database wordmark, intended for dark backgrounds. |
| `03-armory-crest-tactical-red.png` | Reference-based visual refinement of `../v3/03-armory-crest-silver.png` using the built-in image generation tool. |
| `generation-prompt.txt` | Exact instructions used for the raster refinement. |

The rifles return to predominantly green, retaining small silver hardware accents. The bow, arrow, and sword handle receive more silver. The main scope ring becomes silver, with muted red cardinal spokes for a restrained targeting accent. The silver jet, central blade, and green shield retain their established roles.

| Color | Hex | Role |
| --- | --- | --- |
| Vault Black | `#090E0B` | Body, gaps, and presentation background |
| Field Olive | `#617340` | Rifle surfaces and handle grip |
| Tactical Green | `#8AAD45` | Shield border and military accents |
| Structural Green | `#3E5949` | Recessed panels and supporting details |
| Archive Light / Silver White | `#E6EDDF` | Scope ring, bow, arrow, sword, hilt details, jet, and text |
| Reticle Red | `#B54A43` | Small scope spokes and targeting accents |

The SVGs are independent editable interpretations of the refined direction, not exact traces of the generated raster. Marks use a `256 × 256` viewBox; lockups use `920 × 280`. SVGs include accessible titles and descriptions and unique v4 IDs. Wordmark text remains editable with Arial Black, Impact, and sans-serif fallbacks.

This round is saved in `assets/concepts/logos/v4/`. Earlier concepts are preserved. Production adoption, simplified small-size artwork, verification, tests, and builds remain separate from this requested design round.
