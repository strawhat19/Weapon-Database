# Weapon Database — Logo Concepts v1

First identity round for a military vault-style database spanning firearms, swords, custom builds, camouflage, and skins. The concepts use strong silhouettes and restrained green accents.

| Direction | Editable files | Idea and likely use |
| --- | --- | --- |
| 01 — Vault Core | `01-vault-core-mark.svg`, `01-vault-core-lockup.svg` | An octagonal vault emblem with archive chambers. The clearest expression of a secure weapon collection; suitable for the main identity, app icon, and header. |
| 02 — Armory Crest | `02-armory-crest-mark.svg`, `02-armory-crest-lockup.svg` | A sword and simplified rifle inside an angular shield. Emphasizes the breadth of the armory; suitable for collection badges, avatars, and a more overt military identity. |
| 03 — Modular WD | `03-modular-wd-mark.svg`, `03-modular-wd-lockup.svg` | A WD monogram assembled from armor panels with three finish swatches. Emphasizes customization, skins, and camos; suitable for the app icon, customization tools, and compact navigation branding. |

Vault Core is the recommended starting direction because its symbol expresses the vault and database idea without depending on a specific weapon category.

| Color | Hex | Role |
| --- | --- | --- |
| Vault Black | `#090E0B` | Solid emblem bodies and presentation backgrounds |
| Field Olive | `#617340` | Secondary identity color and modular panels |
| Tactical Green | `#8AAD45` | Primary identity accent and active visual emphasis |
| Structural Green | `#3E5949` | Frames, seams, and supporting geometry |
| Archive Light | `#E6EDDF` | Wordmark text and small contrasting details |

Every SVG has a transparent surrounding canvas, accessible title and description, and editable geometry. Marks use a `256 × 256` viewBox; lockups use `920 × 280`. The pale lockup text is intended for a dark background. Wordmarks remain live editable text with Arial Black, Impact, and sans-serif fallbacks; appearance depends on the fonts available on the viewing device.

`04-military-logo-exploration.png` is an AI-generated comparison sheet made with the built-in image generation tool. It explores the same three directions independently; the SVG files are the editable geometric concepts, and the comparison sheet is a separate visual interpretation. Its exact generation prompt is saved in `generation-prompt.txt`.

This round contains design concepts only. Application adoption and mockups are separate follow-up steps. Verification, testing, and builds are left to the project owner, as requested.
