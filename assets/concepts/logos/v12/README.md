# Weapon Database — Armory Crest v12

Two border variants keep v11's green rifles with subtle gray hardware. Both preserve the gray bow/arrow, sword grip, shield panels and jet rear details; silver blade and scope; black insets; tiny reds; scope gaps; and blended rifle-over-sword center.

| Variant | Border treatment | Likely use |
| --- | --- | --- |
| Green Border | Tactical green band with restrained gunmetal/dark silver recessed shoulder and flank inlays. | Main military identity, app icon, avatar, or header. |
| Gray Border | Gunmetal band with restrained dark silver edge details and small green shoulder/flank inlays. | Alternate metal finish or darker header treatment. |

The gray-border variant also keeps green guns. This round varies the crest border alone.

Both cards retain the stacked and horizontal logos, full palette, supporting accent swatches, custom stencil wordmark label and proposed font pairing. The original wordmark remains custom artwork. [Saira Stencil One](https://github.com/Omnibus-Type/Saira) is the display companion and [Rajdhani](https://github.com/itfoundry/rajdhani) the interface/data family; SVG live text uses Arial Black / Impact / sans-serif fallbacks.

Raster assets use built-in image generation. Card font specimens are visual approximations; hex values are intended tokens. SVGs are independent editable interpretations rather than exact raster traces, with accessible titles/descriptions, unique v12 IDs and transparent surrounding canvases.

All new assets are in `assets/concepts/logos/v12/`. Earlier versions are preserved. No application adoption, tests, builds, validation or UI checks were requested or run.
