# Weapon Database — Armory Crest v18

This round refines the selected v17 crest using the supplied v15 detail references. It preserves the current colors and native mirrored construction while restoring the stronger gun silhouettes and black separations.

The jet's black wing apertures are slimmer and angled, with softly rounded outside ends and crisp inside cuts like the v15 reference. The bold outlines, white tail and subtle rear-wing gray facets continue from v17.

The rifles have a distinct barrel-to-handguard gap and regular angular rail spikes with deeper black spaces between them. Tapered grip extensions recreate the pointed inner silhouette from v15. The magazines have black boundaries and a separated upper mouth; their full-length gray rails remain clipped to the smooth magazine body. The lower green bands have clear black separation from both the magazines and stock ends.

Each bottom stock is rebuilt as an open hooked skeleton with a bolt ear, a curved lower notch, a slender sloping return leg, an inset gray reinforcement and a dark-red pin. This restores the v15 stock character with clean controlled geometry. All paired rifle details use the same reflected artwork about x = 394; the jet's wings reflect about x = 614. The SVG contains no embedded images or font dependencies.
