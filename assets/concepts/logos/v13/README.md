# Weapon Database — Armory Crest v13

This requested refinement continues v12's green-border crest. It keeps green rifles with subtle gray hardware and restores the subdued green angular panels extending inward from the shield's inner corners and sides. Extremely small gunmetal seams and dark muted red pins add definition near the lower rifle-to-sword blend.

The bow/arrow details, sword grip, jet rear shading and border inlays retain their grays. The silver blade and scope, black insets, existing tiny reds, scope separation and blended rifle-over-sword silhouette continue unchanged.

The new rifle-to-sword details are deliberately smaller and darker than the existing selector dots. This round preserves the fused center rather than extending a foreground blade through the rifles.

The card retains the stacked and horizontal logos, main palette, supporting accents, custom stencil wordmark label and font pairing. The original wordmark remains custom artwork. [Saira Stencil One](https://github.com/Omnibus-Type/Saira) is the proposed display companion and [Rajdhani](https://github.com/itfoundry/rajdhani) the interface/data family. SVG live text uses Arial Black / Impact / sans-serif fallbacks.

Raster artwork uses built-in image generation. Font specimens are visual approximations; hex values are intended tokens. SVGs are independent editable interpretations rather than exact raster traces, with accessible titles/descriptions, unique v13 IDs and transparent surrounding canvases.

All new assets are in `assets/concepts/logos/v13/`. Earlier versions are preserved. No application adoption, tests, builds, validation or UI checks were requested or run.
