# Weapon Database — Armory Crest v5

This round refines the selected Armory Crest with less red on the target and small red accents distributed through the equipment. The existing layout and military black, green, and silver identity continue.

| File | Purpose |
| --- | --- |
| `01-armory-crest-mark.svg` | Editable standalone crest with transparent surrounding canvas. |
| `01-armory-crest-lockup.svg` | Editable crest beside the two-line Weapon Database wordmark, intended for a dark background. |
| `03-armory-crest-balanced-accents.png` | Visual refinement of `../v4/03-armory-crest-tactical-red.png` made with the built-in image generation tool. |
| `generation-prompt.txt` | Exact instructions used for the raster refinement. |

The scope ring stays silver, with most spokes returning to silver and only short red targeting tips remaining. The silver jet receives tiny red trim. The silver bow and arrow gain small red details and green grip/shaft accents. Both rifles receive more black recessed panels and small red hardware details while retaining green silhouettes. The sword handle gains a narrow red accent alongside its green grip and silver wrapping.
