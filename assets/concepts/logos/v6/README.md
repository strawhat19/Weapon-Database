# Weapon Database — Armory Crest v6

This round adds fine black equipment details to the nearly-approved v5 crest while continuing its existing green, silver, and subtle red balance.

| File | Purpose |
| --- | --- |
| `01-armory-crest-mark.svg` | Editable standalone crest with transparent surrounding canvas. |
| `01-armory-crest-lockup.svg` | Editable crest beside the two-line Weapon Database wordmark for dark backgrounds. |
| `03-armory-crest-black-details.png` | Visual refinement of `../v5/03-armory-crest-balanced-accents.png` using the built-in image generation tool. |
| `generation-prompt.txt` | Exact instructions used for the raster refinement. |

The silver scope spokes gain narrow black insets. The sword grip gains fine black seams between its existing silver wraps. The bow and arrow gain small dark grooves and inlays, and the silver jet gains restrained wing and fuselage panel seams. The existing rifles, red trim, green shield, layout, and wordmark continue from v5.

Both have accessible titles and descriptions and unique v6 IDs. Wordmark text remains editable using Arial Black, Impact, and sans-serif fallbacks.
