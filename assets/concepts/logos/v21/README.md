# Weapon Database — Armory Crest v21

This round refines the selected v20 crest with the straighter grip extensions and black separations from v15. The palette, transparent canvas and native vector construction are preserved.

The trigger grip extensions have straight rear walls and heel edges, ending in single sharp tapered tips. The shared geometry is reflected across the sword centerline, preserving identical angles and proportions on both sides.

The receiver upper edges and metallic insert undersides now follow straight lines parallel to the rifle axes. The lower receiver slots have 4px black separators. Continuous 4.5px black separators run across the magazine mouths, replacing the angular mouth reliefs. They sit above the magazine rail layers so the silver details meet a clean black boundary.

The two existing central gray rails sit inside mirrored black recesses. The recesses add mechanical definition to the joining area and stop above the existing fasteners.

The continuous directional crossing channel, central tang, sword-to-scope clearance, sword handle bands, forearm details, jet, bow, shield and stock hardware continue from v20. Paired details remain mirrored, with the chosen directional front/back overlap at the crossing.

The SVG contains native named paths, shapes, groups and mirrored references, with no embedded raster images or font dependencies. The PNG is rendered directly from this master.
