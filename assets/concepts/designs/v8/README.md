# Armory Vault — Cleaner Steel

V8 uses v2 as its base for a cleaner, more elegant steel treatment. It restores the translucent steel Sign In button, outlined archive badge, single-pixel gray search border, and gray caption, Loadout Lab, and footer rules. Light-theme text returns to charcoal.

The slightly muted interface greens from v7 remain (`#7EB638` and `#3D5844`). The v5 oval retains its exact geometry, palette, and opacity. The official crest, fonts, spacing, rifle, and steel images are preserved.
