# Armory Vault — Archive Details

V9 preserves v8’s layout, materials, palettes, fonts, official crest, rifle, and v5 oval. Restrained native vector details refine the archive UI: a sparse specimen label and fine serial marks above the rifle, quiet featured-entry pagination below the oval, and a subtle selected-skin checkmark. Desktop also adds a small optic annotation leader, an active Catalog underline, and a search keyboard-shortcut cue.
