# Armory Vault — Softer Accents

V6 retains the v3 designs, layouts, typography, and steel treatment, with the v5 oval behind the rifle unchanged. The official crest remains exact. UI black and green tones are softened slightly: black `#080A09`, green `#7EB638`, and olive `#3D5844`. The dark steel field uses `#050706`; light-theme text uses `#080A09`.
