# Armory Vault — Oval Steel Recess

V5 uses v3 as its exact layout and material base. A subtle native SVG oval steel recess and rim sit behind the rifle, with sparse black and green hardware details. Dark and light themes each include desktop and mobile layouts; paired boards place mobile immediately beside desktop on the right.
